Emoji 卡图

用单个 emoji 或双 emoji 融合图制作卡图。仓库自带素材可离线使用；其他组合首次联网获取后保存在本机浏览器。

从已有卡图配置开始

导入配置会填入下方的 emoji、融合来源、背景配色和文件名，之后仍可调整。也可以直接在下方制作新卡图。

支持卡图配置 emoji-recipes.json 和图标配置 ui-icons.json。这里导入的是绘图设置，不是 PNG 图片或游戏卡牌内容包。

也可在输入框直接粘贴 emoji。没有融合图的组合会提示更换。

导出完整卡图或透明图标。普通 emoji 外观跟随系统字体。

本机融合缓存与离线分享

新下载的融合原图保存在当前浏览器中，重新打开可复用。清理浏览器数据或使用隐私模式可能丢失缓存；导出 JSON 可备份，也可交给另一台电脑导入后离线使用。

如需让素材随仓库分发，按工具说明将缓存加入仓库。浏览器缓存不会自动上传到 Git。
