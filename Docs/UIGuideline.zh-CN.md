# EOTA · 界面设计规范

客户端采用深色桌面、暖纸卡牌与黄铜强调色。布局围绕玩家当前的决策组织：操作、操作所需的信息和反馈放在一起，避免在屏幕两端来回寻找。

## 信息层级

| 层级 | 内容 | 呈现方式 |
|---|---|---|
| 主要 | 手牌、英雄生命、可用费用、开始／提交 | 大尺寸、高对比，靠近操作位置 |
| 辅助 | 职业、牌组、难度、回合阶段、提交倒计时 | 常规文字，与所属对象成组 |
| 按需查看 | 随机种子、完整协议、回放与诊断工具、卡牌长说明 | 折叠设置、菜单或悬停详情 |

一个页面只有一个主要动作。主按钮使用黄铜填色；导航使用浅底与底边强调；清空、返回、重随等辅助操作使用较弱的外观。危险操作继续使用确认对话框。状态变化同时通过文字、禁用状态或标记表达，不只依赖颜色。

## 颜色与字阶

颜色和控件状态集中在 [GameTheme.tres](../Client/Godot/GameTheme.tres)，脚本公用颜色在 [Ui.cs](../Client/Godot/Ui.cs)。

| 用途 | 色值 |
|---|---|
| 桌面底色 | `#171d1b` |
| 面板／抬高面板 | `#222625`／`#2b302d` |
| 轮廓 | `#424642` |
| 正文／次要文字 | `#e7e5d8`／`#b5b9a8` |
| 主要动作／按钮文字 | `#c4aa7a`／`#24281e` |
| 卡牌纸面／卡牌正文 | `#d6ccb6`／`#3a3c30` |

正文使用常规字重 400，标题使用 600；字体优先 Microsoft YaHei UI、Microsoft YaHei、Noto Sans CJK SC。避免整屏粗体与纯白文字。卡图继续沿用职业配色，数值减少／增加保留明确的红／绿提示。

以 1600×1000 逻辑画布为基准：页面标题约 34–38，英雄生命与费用 34，主动作 20–24，正文 17–18，说明 14–16；小卡上的紧凑标签可用 12–13。卡面只展示两行摘要，完整说明通过详情阅读。

## 大厅与准备界面

顶部主入口为「开始对战」「牌组工坊」「卡牌图鉴」。回放、协议与编辑器收纳到「更多」。开始对战下再显示人机、本机双人、加入服务器、本机开服四种方式。

人机／双人准备页将双方职业与牌组并排居中，难度紧邻 AI 牌组，下方是开始按钮。随机种子与协议入口放在默认收起的「对战设置」中。开服页将房间配置和启动操作放在左侧，运行状态与邀请放在右侧；加入页按地址、牌组、核对房间的顺序排列。

## 战场

双方英雄居于战场上下中央，生命值放大，手牌与牌库数缩小。六条路线居中排列，上方属于对手，下方属于自己；手牌集中在下方。右下方依次排列阶段、限时提示、可用费用、提交按钮和操作反馈，形成统一的决策区域。

主要区域在逻辑画布中的位置：

| 区域 | 位置与尺寸 |
|---|---|
| 对方英雄 | `(632, 10)`，`336×76` |
| 六路战场 | `(252, 94)`，`1096×530` |
| 己方英雄 | `(632, 626)`，`336×76` |
| 手牌 | 从 `y=728` 开始，底部保持在画布内 |
| 费用／提交／反馈 | 右下方，同一列，避开手牌 |

返回大厅位于左上。重开、保存回放、联机诊断及动画控制收纳到右上「对局菜单」，按模式显示可用项；本机交接入口靠近己方区域。回放进度条保留在顶部。按 Escape 可收起菜单并清除当前卡牌选择。

卡牌详情显示在所指卡牌旁边，边缘自动限制在视口内，移开后隐藏；详情浮层不抢占源卡牌的鼠标事件。空闲时不保留占据整列的详情面板。英雄、路线与卡牌的完整状态仍可通过提示查看。

六路无需横向滚动；协议增加到十二路时允许横向滚动。超过手牌容纳数量时可滚动到最后一张，提交按钮与操作反馈不得覆盖卡牌。换牌、等待对手、结算和结束状态必须清晰地反映在主按钮上。

## 图鉴、牌组与工具

- 图鉴：搜索与职业筛选放在卡池上方，详情与衍生卡导航靠近卡池右侧；点击锁定详情，再次点击取消。
- 牌组：紧凑横向牌组项；编辑页将牌组名称、张数、已选列表和保存按钮放在同一栏。默认牌组与清空是辅助操作。
- 编辑器：左侧选卡，中间编辑，右侧预览与保存；错误紧邻预览显示。完整 JSON 与内容包操作使用已有次级页签。
- 协议与回放：限制内容宽度，让选择、说明与主要动作相邻；长内容使用内部滚动。
- 交接、确认与协议核对：继承同一主题，保留私有手牌遮挡和确认流程。

## 实现与验证

布局源文件在 [Client/Godot/Scenes](../Client/Godot/Scenes/README.zh-CN.md)。[GameApp.Interface.cs](../Client/Godot/GameApp.Interface.cs) 绑定折叠设置、导航、战场工具和详情定位；[TableBackdrop.cs](../Client/Godot/TableBackdrop.cs) 绘制轻量桌面装饰。新增元素应复用主题，装饰不得遮挡输入。

窗口保持 1600×1000 的画布比例。调整后分别用 1600×1000 与 1280×800 执行 `--smoke-ui-review` 并查看截图；用 `--smoke-interactions` 验证点击、拖放、撤回、交接及衍生卡导航。涉及编辑、构筑或播放控制时补跑对应冒烟入口。命令见 [工具说明](../tools/README.zh-CN.md#客户端冒烟测试)。测试使用独立用户数据目录，避免覆盖实际牌组和回放。
