# ADR-018：基础触发器的结算边界

- 状态：Proposed
- 日期：2026-09-08
- 基线：[ADR-006](006-effect-frame-semantics.md)、[ADR-014](014-combat-damage-frames.md)、[ADR-015](015-turn-progression-and-cleanup.md)。

## 背景

系统阶段已具备单帧提交。基础效果需要在确定的因果边界进入同一管线，并保留后续复杂 Continuation 的接入位置。

## 决定

- 部署提交后收集全部入场事实，进入 EntryEffects 后在同一效果帧求值对应根节点。
- 同速度法术的自身使用效果与法术消耗属于同帧，均读取帧开始快照；本路友方法术使用触发在该帧提交之后执行。
- 每个提交后的事件批次收集一批触发调用，按 EventId、来源 CardInstanceId、效果根 ID 排序；各根读取同一下一帧快照。产生的新事件只能安排后续帧。
- 战斗宣告、主动攻击宣告、先攻伤害和最终伤害之间分别运行触发批次至稳定。宣告固定参与者与目标；触发后可失去资格，不补选攻击者或重定向目标。
- 先攻实际出手集合在先攻伤害前冻结，后续移除先攻不能使来源在最终帧再次造成普通伤害。斩杀仍按 ADR-014 在最终帧生成。
- 回合结束先运行存活随从的结束效果至稳定，再从新快照收集存活场地的结束效果。充能窗口由后续阶段补齐。
- 自身受伤由提交后的正伤害聚合事实触发，包括本帧致死伤害；已移除来源可以读取冻结的最终属性，但 self 目标不重新指向该墓碑。
- 终局或 Failed 后丢弃后续触发。每回合触发帧数、每效果帧 Intent 数受协议预算限制，超限使用正式 Error 帧停止推进。

## 影响与边界

触发执行采用有界迭代，不递归提交，也不读取客户端动画或墙钟。效果中的空目标、条件不成立使用 NoOp。

P6 的批次在 TurnResolver 内推进；这里只提供基础冻结来源支持。可恢复的通用队列、Sequence、ReceiptLedger、生命周期优先级和完整冻结观察者合同仍属于 P7，不能把单帧状态当成已保存全部待执行任务的检查点。首个正式协议冻结前统一复核。
