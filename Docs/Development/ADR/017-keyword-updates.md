# ADR-017：关键词添加、移除与迟缓获得边界

- 状态：Proposed
- 日期：2026-09-08
- 基线：[ADR-012](012-deployment-replacement.md)、[ADR-013](013-combat-eligibility-and-slow.md)。

## 背景

效果使静态关键词成为可修改状态，需要定义同帧冲突，以及战斗中移除、重新获得迟缓后是否消耗次数。

## 决定

- 按实体与关键词合并更新；同帧 Remove 优先于 Add，多份普通 Add 等价于获得一次关键词。
- slow 的多份 Add 取已有剩余次数与所有新增次数的最大值；Remove 清除关键词和计数。
- 随从支持其全部内建关键词。场地仅支持 replace/replaceable，默认仍不具备替换权限。
- slow 从无到有时递增获得代数；战斗开始记录实体身份与当时的代数。
- 战斗结束只扣减仍存活且代数相同的旧迟缓。战斗中首次获得、或移除后重新获得的迟缓不在本次战斗后扣减。旧迟缓被延长但没有移除时仍扣减一次。

## 影响

所有变动经 Intent/Reducer 提交并进入状态哈希。代数属于权威内部身份，不向客户端公开；客户端只看剩余次数与关键词。

该边界补充 ADR-013 的计数消耗，不改变 slow 同时禁止主动攻击、防守且 swift 不能覆盖的已接受规则。首个正式协议冻结前统一复核。
