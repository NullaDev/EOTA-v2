# ADR-003：权威数值语义

- 状态：Accepted
- 日期：2026-09-04
- 接受日期：2026-09-06

## 通用数值规则

- 权威离散数值使用有符号 64 位整数并显式规范编码。
- 普通算术使用 checked 语义；溢出产生稳定 `ArithmeticError`，不允许回绕。
- 同帧加减先在完整冲突组中合并，再应用一次。
- 乘除使用规范有理倍率；分子分母约分且分母为正。组合阶段需要时使用 BCL `BigInteger` 中间值，最终校验回 64 位整数。
- 整数舍入只在最终阶段发生一次，方向为向零取整。
- 浮点数不进入权威状态、表达式、回执或哈希。

底层修正后的权威值可以是负数；“显示值”和“用于某项动作的有效值”是从权威值派生的视图，不能反向覆盖原值。

## 分属性规则

- 英雄拥有独立、可变化的当前生命与最大生命；两者初始值均来自协议的 `InitialHeroHealth`。英雄最大生命的实际变化量同步作用于当前生命，规则与随从一致。
- 英雄当前生命小于等于 0 时死亡。英雄和随从的治疗都不能超过同帧归约后的最大生命；回执和事件记录实际恢复量。
- 随从攻击没有规则下限；显示攻击和实际造成的伤害均为 `max(0, authoritativeAttack)`。负攻击不会变成治疗。
- 随从当前生命或最大生命小于等于 0，或被显式 Kill 时死亡。
- 卡牌费用没有规则下限；显示费用和实际支付费用均为 `max(0, authoritativeCost)`。负费用不会给玩家返还资源。
- 有限场地持有能量；能量小于等于 0 时立即破坏。
- 永久场地是与有限能量场地分型的生命周期接口，不使用极大值或负数作哨兵。永久场地没有可显示能量，回合结束不执行自然能量衰减，但仍可被显式破坏、替换或放逐。

最大生命的实际变化量会同步作用于当前生命，然后才结算同帧伤害与治疗。例如当前生命 2、最大生命 5 的随从受到 `-2/-2` 时，最大生命变为 3，当前生命同步变为 0，因此仍会死亡；死亡条件不是只看变化后的最大生命。

同一目标有多份治疗但恢复空间不足时，最终生命只取决于治疗总量；各 Intent 的实际恢复量按稳定 `IntentId` 分配，以保证每份回执唯一且与枚举顺序无关。

除 `Int64` 与 checked 算术边界外，攻击和费用不设置额外硬下限。将来若某个协议需要上限，必须作为按属性命名的协议字段加入并进入 `ProtocolHash`，不能散落为实现常量。
