## 1. 开始第一局

### 启动与选择模式

将 Windows 发布包完整解压，运行 `EOTA.exe`。第一次可以这样设置：

1. 在大厅选择“人机对战”。
2. 选择自己的牌组和 AI 的牌组。先使用默认牌组即可，不必先学会构筑。
3. 将 AI 难度设为“简单”。第一局可以选守卫或猎人，先观察部署、防守与攻击。
4. 保持默认“对战协议”和随机种子，点击“开始人机对战”。

“本机双人”适合两人在一台电脑上轮流操作，也可用于自己观察双方视角。提交一方的规划后，点击“切换席位”，由下一位玩家确认交接后操作；这只是操作席位的切换，双方的牌仍按同一回合的阶段统一结算。

### 选择起手牌

默认起手 **4 张**，开启换牌。点击不想保留的牌，再点击“确认换牌”；一张都不选也可以确认。

优先保留能在前几回合使用的低费用牌，让自己尽早拥有能防守的随从。换出的卡会先放到一边，补完牌后才重新洗回牌库，因此不会立刻抽回刚换走的**同一张卡牌实例**；牌组里其他同名副本仍可能被抽到。

双方都确认后进入第 1 回合。默认从 **1 点可用费用、1 点费用上限**开始。

### 试着完成一次规划

点击手牌，再点击高亮的合法路线；也可以直接把牌拖到路线中。放错位置时，在提交前点击对应的规划条目撤回，卡牌和预留费用都会返还。

如果没有合适的牌，可以不出牌直接提交。第一次先观察“牌进入战场”和“随从能否攻击”，不用急着每回合都打出最多的牌。

## 2. 默认规则与战场界面

### 默认数值

| 项目 | 默认设置 |
| --- | --- |
| 双方英雄初始生命 | 各 30 点 |
| 战场 | 6 条路线 |
| 牌组 | 恰好 40 张，单个卡牌 ID 最多 3 张 |
| 正常构筑卡池 | 本职业基础卡与中立基础卡 |
| 起手与换牌 | 4 张，开启换牌 |
| 手牌上限 | 9 张 |
| 第 1 回合费用 | 可用 1，上限 1 |
| 后续回合费用 | 上限每回合增加 1，最高 10，并补满可用费用 |
| 每个后续新回合抽牌 | 每位玩家各抽 1 张 |
| 以太活化 | 每位玩家每路独立，范围 0–3，通常每回合衰减 1 |
| 有限场地耐久 | 清理阶段通常减少 1 |
| 空牌库 | 不疲劳：抽不到牌，但不自动扣血 |

这张表描述默认值。若你改过协议并保存，客户端会继续使用保存的设置，不能再直接套用这张表。

### 看懂画面

![六路战场示例](Images/battlefield.png)

图中是进行到第 5 回合的示例对局：

- **左侧**：双方英雄生命、手牌与牌库数量，以及当前可用费用。费用属于玩家自己，供所有路线共同使用。

## 3. 卡牌、费用与规划

### 三种卡牌

| 类型 | 作用与摆放 |
| --- | --- |
| 随从 | 部署到本方某路的随从位置，用攻击力和生命参与战斗，也可能拥有入场、死亡等能力 |
| 场地 | 部署到本方某路的场地位置，提供持续或阶段效果；有限场地显示剩余耐久，永久场地不会自然到期 |
| 法术 | 按牌面选择路线或全局区域，在快速或慢速法术阶段发动，施放后不作为随从或场地留场 |

随从的两个主要数值是**攻击力／生命**。图鉴显示初始属性；战场上的随从可能已经受伤、获得强化或暂时减弱，应以当前详情为准。场地上的耐久数值不是随从生命，也不是另一份额外“强度”。

插图背景用于辨认职业：守卫蓝色、奥术师紫色、工匠棕色、猎人绿色、中立灰棕色。种族或体系标签另看文字，例如野兽、机械、火器营、血术师，不能仅凭背景颜色推断。

### 使用费用

规划一张牌时会预留其费用，可用费用立即减少。例如本回合有 4 点费用，规划一张 3 费牌后剩 1 点；撤回这张牌后恢复为 4 点。

每个后续新回合会提高费用上限并补满费用。**未用完的费用不会额外累积到下回合**，但留在本回合的费用可能帮助触发充能，所以“还有费用”并不意味着一定要继续出牌。

### 安排与撤回

在费用足够且位置合法时，可以规划多张牌。同一路可分别规划一个随从和一个场地；法术可以有多张，每张会有自己的规划标记。

双方的手牌和未公开规划彼此隐藏。点击“提交回合”后，你本回合的规划就锁定了，不能继续添加或撤回；等待另一方提交后，游戏自动结算。快速法术也必须在规划时安排，不能等看到战斗结果后再临时插入。

如果某路放不下牌，先检查：费用够不够、该路是否锁闭、同类位置是否已经被占用或预约、是否满足替换条件。全局法术需要放在“全局法术”区域，不能当作路线法术摆放。

## 4. 一回合如何结算

双方提交后，按照以下顺序推进。结算期间主要是观察结果，不需要手动点击随从发动普通攻击。

| 顺序 | 阶段 | 会发生什么 |
| ---: | --- | --- |
| 1 | 部署 | 规划的随从与场地进入战场，处理允许的部署替换 |
| 2 | 入场效果 | 处理入场触发，以及牌面写明在部署后的入场阶段发动的效果 |
| 3 | 快速法术 | 双方预先规划的快速法术发动 |
| 4 | 移动 | 游击、追猎等系统自动移动按当前战场判定 |
| 5 | 战斗前充能 | 检查这一时点的充能需求，满足时发动相关能力 |
| 6 | 战斗 | 处理战斗阶段能力、攻击与防守、先攻和最终伤害，之后衰减已有迟缓 |
| 7 | 慢速法术 | 双方预先规划的慢速法术发动 |
| 8 | 回合结束效果 | 先处理回合末充能，再处理随从／英雄的回合末效果，之后处理场地回合末效果 |
| 9 | 清理 | 衰减有限场地耐久、以太与有期限的状态，处理到期效果，再进入下一回合 |

记住三个直接影响出牌的时间差：

- **快速法术在入场效果之后。** 本回合新部署的随从不会先享受到稍后才施放的快速以太活化，再回头触发入场共鸣。
- **快速法术在战斗之前，慢速法术在战斗之后。** 想阻止本次战斗的攻击，需要在战斗之前生效的手段；慢速伤害通常用于战后补刀或处理残留威胁。
- **回合末回血未必来得及救命。** 如果英雄已经在战斗或更早的回合末结算中死亡，对局会停止，之后的场地治疗不会再执行。

同一个结算时点可能同时处理双方、不同路线的效果。动画逐个播放是为了方便观看，不能据此认为左边一定比右边先造成有效伤害。牌面明确写出先后步骤时，按相应步骤执行。

## 5. 随从怎样战斗

### 主动攻击与防守是两件事

普通随从在入场当回合**不能主动攻击，但可以防守并反击**。之后的回合，只要没有守备、迟缓、冻结或场地禁攻等限制，就能主动攻击。

在某一路至少有一方能主动攻击时：

- 对面有能防守的随从，就在本路发生随从交战。
- 对面没有随从，或其随从因迟缓而不能防守，攻击会落到对方英雄身上。
- 对面只有场地时，场地不会代替随从挡住普通攻击。

双方都不能主动攻击时，不会因为两个随从面对面站着就自动互打。随从默认只负责所在路线；另一条路上的守备随从不会替这里的英雄伤害挡刀。

### 普通交战示例

假设双方本路随从均没有特殊能力，一方是 3/4，另一方是 2/3，且至少一方有主动攻击资格：它们在普通战斗伤害中互相造成 3 和 2 点伤害。2/3 的随从生命降到 0 并死亡，3/4 的随从剩 2 点生命。

这次打死随从的多余攻击不会自动转成英雄伤害；先攻击杀了对方随从，也不会再把同一次攻击改打英雄。

### 常见关键词

| 关键词 | 规则与容易误解的地方 |
| --- | --- |
| 迅捷 | 解除“入场当回合不能主动攻击”的限制；不能覆盖守备、迟缓或整路禁攻 |
| 守备 | 自己不主动攻击，受到攻击时仍可防守反击；它不是保护所有路线的嘲讽 |
| 迟缓 N | 剩余次数大于 0 时既不能主动攻击，也不能防守。战斗开始时已有的迟缓，在战斗结束后通常减 1，即使没有发生交战也会减少 |
| 先攻 | 只有一方有先攻时，它先造成随从战斗伤害；若杀死目标，目标不能反击。双方都有先攻时仍同时互相伤害 |
| 斩杀 | 参与随从战斗伤害时可直接消灭对撞随从，不要求单靠攻击数值扣光生命；先攻阶段已经死亡的来源不能再贡献斩杀。这不等于打英雄就直接获胜 |
| 吸血 | 由实际对敌方英雄造成的战斗伤害恢复己方英雄生命；对随从的普通战斗伤害不会产生吸血 |
| 游击 | 本路有敌随从时，尝试移动到没有敌随从的相邻路 |
| 追猎 | 本路没有敌随从时，尝试移动到有敌随从的相邻路 |
| 替换 | 新部署的这张牌可以替换本方对应位置的已有对象 |
| 可替换 | 已在场的这个对象允许被本方同类新对象替换 |

例如迟缓 1 的随从在第 3 回合部署：第 3 回合战斗中不能攻击，也不能挡住敌人；战斗结束后迟缓减为 0，通常从第 4 回合起可以正常交战。战斗过程中才新获得的迟缓，不会立刻在同次战斗末白白减少一次。

临时增加最大生命、临时攻击加成等效果结束后，会移除对应加成。临时生命加成到期也可能导致受伤随从死亡，不能把临时生命当成永久治疗。

<a id="lanes"></a>
## 6. 路线移动、冻结与锁闭

### 自动移动

游击和追猎在移动阶段判断路线。目的地必须是相邻路，且在这一批移动开始时，本方随从位置已经空闲；不能把“另一个随从也准备移走”当成空位。

默认方向是**优先向外侧**。多个随从争抢同一位置时，默认由来源路线更靠近战场中央的一方优先；没有竞争成功的随从留在原位，不会再自动尝试另一边。房间协议可以修改这些选择规则。

因此，带游击的单位可能离开你原本希望它防守的路线；带追猎的单位也可能主动找上敌方随从，而不是继续攻击英雄。

### 雪花与锁分别代表什么

| 状态 | 影响 |
| --- | --- |
| 冻结 | 整路双方不能主动攻击，但不会因此禁止施法、效果伤害或移动 |
| 锁闭 | 禁止该路的部署、召唤、移动进出、回手与替换；仍可对该路施放法术，死亡、放逐和场地到期也仍会发生 |

两种状态都作用于整条路，不能只按施法者一侧理解。某些场地本身也禁止本路主动攻击；移除雪花状态，并不会同时移除场地提供的禁攻。

## 7. 以太、共鸣、充能与蓄能

### 以太与共鸣：看的是自己这一侧的路线

每位玩家在每条路都有独立的以太活化等级，默认从 0 到 3。卡牌所说的“活化”会改变相应路线的等级；“共鸣 1／2／3”通常要求在效果判断时，来源所属玩家的该路以太达到对应等级。

以太不是用来支付普通出牌费用的第二个钱包。它决定某些效果能否发动或采用哪一种强度，例如一张牌在没有共鸣时只提供基础效果，达到共鸣 2 后可能额外获得强化。

默认每次清理会让以太减少 1，最低为 0；保护下一次衰减的效果可以抵消一次自然减少。部分强力能力发动后还会清空以太，具体看牌面。

例如本路原本是 0，以快速法术活化 1：它能赶上本回合战斗和回合末的共鸣判断，但如果没有保护，清理后通常又回到 0。想让下一回合新随从的**入场共鸣**生效，需要提前准备能保留下来的以太。

### 充能与蓄能：有时应该保留费用

某些随从或场地写有“充能 N”，在战斗前或回合结束检查是否能发动。默认计算方式是：

**这一时点自己的全部充能需求之和 ≤ 当前剩余费用 + 全场友方存活随从与场地提供的蓄能总量。**

同一玩家、同一时点的充能作为一批处理：资源够则这一批都触发，不够则这一批都不触发。判断通过本身不会扣掉这些费用或蓄能；能力正文若还要求消耗其他资源，则另按牌面执行。

例如你剩余 2 点费用，友方场地提供蓄能 2；两项战斗前充能分别需要 1 和 3，总需求为 4，这一批可以发动。如果又出了一张 1 费牌，资源变成 3，总需求仍为 4，这一批便都无法发动。

蓄能不能拿来支付普通卡牌费用；它参与的是充能检查。迟缓不妨碍单位提供蓄能。部署完成时已在场的来源可以参与本回合充能，之后由效果新召唤或变形得到的来源通常要等到下回合才作为新的充能来源参与。

## 8. 场地、死亡、回手与替换

有限场地用剩余耐久表示还能维持多久，默认在每回合清理阶段减少 1。耐久耗尽后离场；如果场地带有对应死亡效果，还会按规则触发。永久场地不自然衰减，但仍可能被允许的消灭、放逐或替换效果处理。

同一路本方可以同时有一个随从和一个场地。要在已经占用的位置部署同类对象，必须满足以下任一条件：**新对象有“替换”**，或**旧对象有“可替换”**。普通随从不会仅因为费用更高就能覆盖旧随从。

| 离场方式 | 对新手最重要的区别 |
| --- | --- |
| 死亡／消灭 | 会进入死亡处理，能够触发相应死亡能力 |
| 替换 | 旧对象离场，新对象以自己的初始属性进入；旧对象不会因此触发死亡能力 |
| 回手 | 成功时移除场上对象，把对应卡牌放回手中；重新按原型属性使用，不保留原有场上增益 |
| 放逐 | 从战场移除，不能当作普通死亡来期待死亡衍生能力 |

“生成一张牌到手中”和“在战场召唤一个随从”也不同：前者仍需要你以后规划出牌，后者直接尝试进入合法战场位置。衍生卡通常通过这些效果获得，默认不能直接加入牌组。

持续毒伤等附加效果应查看剩余次数或期限。有些毒伤可以叠加并分别计时，不能认为再施加一次只是刷新同一个计时器。

<a id="ending"></a>
## 9. 抽牌、疲劳与胜负

默认每个后续新回合各抽 1 张，卡牌效果还可能提供额外抽牌。手牌上限是 9 张：手牌已满时，仍从有牌的牌库抽出的牌会被烧掉，不会自动挤掉已有手牌。

默认不疲劳，牌库为空后只是抽不到牌。房间也可以选择另外两种疲劳规则：

| 疲劳规则 | 空牌库继续抽牌时 |
| --- | --- |
| 不疲劳 | 抽不到牌，不扣生命 |
| 递增伤害 | 自己第一次空抽受到 1 点伤害，第二次 2 点，第三次 3 点，以此类推 |
| 疲劳即死 | 下一次空抽直接斩杀自己的英雄 |

**抽走最后一张牌不会立即疲劳，继续尝试抽牌才会。** 一次抽 3 张而牌库只剩 1 张时，会先抽走最后一张，再产生两次空抽。疲劳次数分别属于两位玩家，不会因下一回合或重连而清零。

英雄生命在结算检查时降到 0 或以下，或受到明确的斩杀，即会判定死亡。对方英雄死亡而己方存活则获胜；同一结算帧中双方都死亡则平局。不同阶段不是一次总账：不能期待慢速法术或更晚的治疗挽回已经判定结束的对局。

## 10. 构筑、联机与复盘

### 做自己的牌组

进入“牌组工坊”，新建卡组并选择职业。可以从空白牌组开始，也可以选择一个职业体系模板，再增减卡牌。默认正常构筑要求 40 张、单卡最多 3 张，并且只能使用本职业和中立的基础卡。

当前五职业各有 50 张基础卡；每职业各有 2 张衍生卡，另有 22 张中立卡。每职业有三个可编辑模板，完整牌表与思路见 [十五套体系牌组](Content/ArchetypeDecks.zh-CN.md)。

开始构筑时，先确保前几回合有牌可出、有单位能防守，再考虑高费终结牌。奥术师需要留意以太准备能否赶上共鸣窗口，工匠需要把蓄能、剩余费用与充能需求一起计算。灵魂使可从“亡灵换防”“殉道祭仪”“缝魂逆祷”模板开始：游魂有迅捷但会在随从回合末窗口死亡，僵尸以守备持续占路；治疗联动只计算实际恢复量，满血治疗不会带来额外伤害。所有修改都应点击保存；返回列表保留的未保存草稿只属于本次运行。

### 与朋友联机

1. 房主进入“本机开服”，设置房间名、端口、参考牌组和对战协议，启动后点击“自己加入”。
2. 房主把“玩家二邀请”交给另一位玩家。
3. 加入者在“加入服务器”中填写邀请地址，核对房间协议并选择自己的牌组，确认后加入。

双方可以使用不同牌组；两套牌组实际涉及的卡牌及关联衍生卡，需要拥有一致的规则定义。跨设备时邀请地址与端口必须能互相访问；同一台电脑可用的本机地址不等于对方电脑也能访问。

加入前应核对路数、英雄生命、牌组数量和疲劳规则，避免按默认设置误判。更多房间与构筑选项见 [客户端与房间规则](GameplayGuide.zh-CN.md)。

### 放慢动画，观察自己的决策

顶部可暂停或调整动画速度，也可跳过动画查看当前结果。本地对局可保存回放，再从大厅的“对局回放”入口查看。动画暂停只影响本机观看过程，不会替联机房间暂停提交倒计时。

复盘时可以问自己：是哪一路先出现了防守空缺？快速法术是否赶上关键窗口？是否为了多出一张牌而错失整批充能？是否把带游击或迟缓的随从误当成稳定防线？

牌组、协议、内容包、回放与房间存档默认位于 `%APPDATA%\Godot\app_userdata\EOTA v2\`。

## 11. 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 新随从为什么没攻击？ | 普通入场限制，以及守备、迟缓、冻结或场地禁攻；迅捷只解除第一项 |
| 场上明明有随从，英雄为什么仍挨打？ | 它可能有迟缓而不能防守，也可能根本不在受到攻击的那一路 |
| 为什么放不下第二张随从？ | 每方每路只有一个随从位置；已有单位的替换权限和同回合规划预约都要满足 |
| 为什么快速法术没有强化入场效果？ | 入场阶段先于快速法术阶段，刚施放的活化赶不上更早的判断 |
| 为什么一个充能都没有触发？ | 检查这个时点的全部友方需求之和，而不是只看某一个单位 |
| 对手那边以太很高，我的共鸣为什么没发动？ | 双方同一路的以太也彼此独立 |
| 为什么单位自己换路了？ | 查看游击、追猎或移动效果，以及房间方向偏好 |
| 慢速法术为什么没救下英雄？ | 它在战斗之后；先前已经结束的对局不会继续执行后续阶段 |
| 为什么抽不到牌，或者抽牌后掉血？ | 检查手牌上限、剩余牌库与房间疲劳设置 |
| 图鉴里为什么不能把衍生卡加进牌组？ | 默认构筑只开放基础卡，衍生卡需在对局中通过效果获得 |

熟悉这些规则后，可结合 [完整中文卡表](CardTable.zh-CN.md) 阅读具体卡牌；制作自己的规则内容时，再查阅 [Mod 开发者 JSON 指南](CardJsonDesignGuide.zh-CN.md)。
