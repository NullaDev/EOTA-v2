# ADR-024：有限持续修正与基础攻击分层

- 状态：Proposed
- 日期：2026-09-09
- 承接：ADR-016、ADR-017

## 决定

临时攻击、最大生命和承伤修正记录独立 Add 增量，在回合结束效果全部执行之后按协议衰减期限，到期移除自身贡献。慢速阶段获得 duration=1 的效果也在本回合清理到期。迟缓保留 ADR-013 的战斗计数，不能作为通用 duration 关键词。

基础攻击使用显式 `baseAttack Set`，与既有 `attack` 属性分开。攻击/手牌增益保留在基础值之外：基础 0、永久 +1，再临时设置基础攻击为 4，得到 5；到期后回到 1。部署时原型基础值与手牌实例增益分别保留。

多个临时基础 Set 同帧先按 ADR-016 选出一个；跨帧较晚的生效。到期后露出仍有效的前一层，全部到期后回到永久基础。永久基础 Set 修改底层；普通 attack Set 仍修改最终攻击，数值 Add/Multiply/Divide 延续既有顺序。充能需求覆盖采用同样的期限叠层原则。

临时关键词保存永久基线；同时添加/移除时 Remove 优先，永久移除会清理对应临时添加，避免到期后复活已删除的关键词。正伤害使用帧开始时的 incomingDamageAdjustment，每份伤害分别调整并最低为 0；失去生命不属于伤害。

期限、修正贡献与永久基线属于权威状态和检查点。公开投影提供当前值、修正类别及剩余期限，隐藏 IntentId 和内部回执。这些分层规则为开发提案，首个公开协议冻结前需人工复核。
