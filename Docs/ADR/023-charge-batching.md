# ADR-023：充能批处理与蓄能

- 状态：Proposed
- 日期：2026-09-09

## 决定

部署完成后冻结本回合充能来源的实体身份和卡牌原型；此后新召唤或变形所得来源到下回合再参与。收集时只保留仍存活且原型一致的来源。

战斗前与回合结束分别收集充能根。同一玩家同一时点的所有需求相加，与剩余当前费用加全场友方蓄能总量比较，足够则全部触发，不够则全部不触发。费用与蓄能都不被消耗，不按根顺序抢占。

每个充能根声明非负需求；实体上的 chargeRequirement Set 覆盖其所有充能根的需求。永久覆盖与有期限覆盖均支持，Set 同帧竞争按 ADR-016，期限及叠层恢复见 ADR-024。

回合结束先完整执行充能，再收集随从回合结束根，最后收集场地回合结束根；每个收集窗口完成全部因果续执行后才进入下一窗口。entryStage 根在每回合部署后的入场阶段执行，可在本回合充能判断之前修改需求。
