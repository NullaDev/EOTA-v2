# ADR-021：效果替换与生命周期冲突

- 状态：Proposed
- 日期：2026-09-09
- 承接：ADR-007、ADR-012

## 决定

随从与场地使用相同生命周期归约。既有 Banish > Kill > Return > Transform 扩展为 Banish > Kill > Return > Replace > Transform；自然死亡与显式 Kill/Destroy 同级。Replace 必须满足来源新原型具有 replace 或旧实体具有 replaceable，场地默认不允许替换。

同类 Transform/Replace 优先采用目标控制方提供的请求；同优先级多候选按全局 RNG 裁决。多次 Return 合并为同一实体的一个容量请求；多次 Banish 只移除一次。失败请求拥有自己的回执。伤害、增益等先归约，删除时冻结最终数值，Banish 抑制死亡与普通离场事实。

Transform 保留实体与卡牌实例身份，更新当前卡牌原型，重置旧实例属性、持续增益和附加效果；保留入场回合，更新迟缓应用代数。Replace 新建实体与实例，产生旧实体离场和新实体入场，并携带被替换 Tombstone。

死亡/离场观察者集合取提交前快照，同帧被删除的观察者仍参与；来源与事件主体保存最终冻结实体和原型。后续目标选择只返回可用对象，冻结属性读取独立于可选目标集合。

规划部署中的替换仍在部署系统帧执行，效果 Replace 在效果帧执行；二者共享权限与事实规则。详细阶段隔离见 ADR-019。
