# ADR-013：主动攻击、防守与迟缓计数

- 状态：Accepted
- 日期：2026-09-07
- 接受日期：2026-09-07
- 来源：从 [ADR-010](010-p4-system-gameplay.md) 拆分，保留已确认语义。

## 背景

入场限制、迅捷、守备和迟缓共同决定随从能否参加战斗，需要分开定义主动攻击与防守资格。

## 决定

- 普通随从入场当回合不能主动攻击，但可以防守并反击；`swift` 取消入场攻击限制。
- `guard` 禁止主动攻击，仍可在被攻击时防守并反击。
- 场地的 `preventsActiveAttacksInLane` 阻止本路双方主动攻击。
- `slow X` 剩余次数大于 0 时，同时禁止主动攻击和防守，敌人可以绕过它攻击英雄。
- swift 只覆盖入场攻击限制，不能覆盖 guard、场地禁止主动攻击或 slow X。

战斗开始时已有迟缓的存活实体，在本次战斗结束后减 1；到 0 时移除 slow。是否实际发生交战不影响这次计数消耗。若比赛已终局，则按回合终止规则丢弃后续帧。

## 影响与边界

迟缓使用计数式 slow X，按本决策规定限制主动攻击与防守资格。交战关系和伤害帧使用这些资格，见 [ADR-014](014-combat-damage-frames.md)；阶段推进遵循 [ADR-015](015-turn-progression-and-cleanup.md)。

未来效果在战斗中新增迟缓的获得边界，需结合触发队列继续实现；当前实现范围见 [P4 检查点](../Review/P4-Gameplay-Review.zh-CN.md)。
