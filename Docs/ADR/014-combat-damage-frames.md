# ADR-014：战斗宣告、先攻与最终伤害帧

- 状态：Accepted
- 日期：2026-09-07
- 接受日期：2026-09-07
- 来源：从 [ADR-010](010-p4-system-gameplay.md) 拆分，保留已确认语义。

## 背景

先攻需要允许目标在反击前死亡，而普通伤害、斩杀与跨路线吸血又需要共同裁决，不能按路线顺序即时修改生命。

## 决定

所有路线从同一战斗开始状态确定交战关系，主动攻击和防守资格遵循 [ADR-013](013-combat-eligibility-and-slow.md)。依次执行以下正式帧：

1. 战斗宣告帧，记录交战关系。
2. 主动攻击宣告帧，记录主动攻击事实。
3. 先攻伤害帧及生命周期检查点。
4. 最终战斗伤害帧及生命周期检查点。

单方具有 `firstStrike` 时，先攻帧先造成随从伤害；目标死亡后不能反击，也不把这次攻击重新转向英雄。双方都有先攻时互相抵消，在最终伤害帧同时伤害。

`execute` 在最终战斗帧添加 Kill。只要来源具备随从战斗伤害资格，即使攻击为 0 也生效；最终帧反击致死不会取消已经产生的 Kill。先攻帧已死亡的来源不再产生最终帧 Kill。

`lifesteal` 仅由对英雄的实际战斗伤害产生，对随从伤害不吸血。所有路线的英雄伤害与相应吸血治疗属于同一个最终原子帧，统一归约后才检查英雄死亡；吸血可以救回本帧原本受到致命伤害的英雄。

## 关联决策

伤害有效值、治疗上限与实际恢复量遵循 [ADR-003](003-authoritative-numbers.md)，同帧归约与吸血贡献遵循 [ADR-006](006-effect-frame-semantics.md)，死亡与终局处理遵循 [ADR-007](007-lifecycle-and-tombstones.md)。本决策确定战斗帧的划分与关键词生效时点。
