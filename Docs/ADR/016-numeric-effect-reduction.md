# ADR-016：数值效果归约与 Set 冲突

- 状态：Proposed
- 日期：2026-09-08
- 基线：[ADR-003](003-authoritative-numbers.md)、[ADR-005](005-global-rule-rng.md)、[ADR-006](006-effect-frame-semantics.md)，以及架构文档引用的 VNext 冲突表。

## 背景

效果可以同时修改一个属性。Set、加减和倍率必须在完整冲突组上决定，不能依赖效果求值顺序。

## 决定

每个目标的每个整数属性独立归约：

1. 从合法 Set 候选中优先保留由目标控制方产生的候选；没有己方候选时使用敌方候选。
2. 候选按 IntentId 排序，使用 GlobalRuleRng 选一份。多个候选即使值相同也抽样；单候选不消费样本。没有 Set 时使用帧开始值。
3. 合并加减，再合并乘除倍率。倍率使用 BigInteger 中间值并约分、保持正分母；最终只向零取整一次，然后应用属性范围与 Int64 检查。
4. 同帧其他分支产生 Error 时，整个提交及 RNG 消费一起回滚。回放保存候选、所选 IntentId 和采样前后计数，客户端不接收这些记录。

原有 ModifyMinionStats/ModifyFieldEnergy 的加减贡献参与同一归约。最大生命变化保持 DamageTaken，因此实际变化量同步到当前生命；直接修改 DamageTaken 属于属性变化，不产生受伤或治疗事实。普通伤害与治疗在属性归约之后合并，显式 Kill 不被治疗抵消。

## 影响

排列输入不会改变状态、回执、事件或 RNG。选择失败的 Set 产生 Rejected，不阻止独立加减和倍率。不存在或类型不匹配的目标不会进入 Set 抽样。

本记录细化开发协议的数值冲突，未修改 Accepted ADR 中的攻击负值、有限/永久场地分型、治疗上限或死亡条件。首个正式协议冻结前统一复核。
