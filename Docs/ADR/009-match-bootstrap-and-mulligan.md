# ADR-009：开局 Bootstrap 与起手换牌

- 状态：Accepted
- 日期：2026-09-06

## 决定

洗牌、发起手牌和可选换牌属于比赛 bootstrap，不使用日常 `DrawIntent`，也不触发抽牌、手牌容量、疲劳或卡牌效果。

`GameProtocol.MulliganEnabled` 决定是否进入独立 `Mulligan` 阶段。默认协议可以关闭换牌，但 Kernel 必须保留完整能力。

## 换牌流程

1. 玩家只能选择自己本次起手中的 `CardInstanceId`，每张至多一次。
2. 双方选择彼此隐藏并分别提交；未选择任何牌也是合法提交。
3. 在双方都提交后统一执行，固定按 PlayerId 处理，网络到达顺序不能影响 RNG 或牌序。
4. 每位玩家选中的牌先被暂时搁置，从当前牌库顶补充等量卡牌，因此不会立刻重新抽到刚换走的牌。
5. 原起手实例随后放回剩余牌库并用全局规则 RNG 重新洗牌。换牌数量为 0 时不额外消费 RNG。
6. 换入与换出的都是 bootstrap 中已有的卡牌实例，不创建新 `CardInstanceId`；这不属于游戏内 Return 操作。
7. 换牌结束后进入正常 Planning 阶段，且不产生普通抽牌触发。

若剩余牌库少于所选数量，命令被稳定拒绝。协议编译不强制牌组至少为起手牌的两倍，以便测试或特殊模式自行限制最大换牌数。
