# ADR-022：召唤与移动的槽位竞争

- 状态：Proposed
- 日期：2026-09-09
- 承接：ADR-011

## 决定

召唤随从/场地进入玩家、路线、槽位类型组成的冲突组。只考虑帧开始时空闲的槽位；同帧死亡、回手或移动离开的槽位不成为新候选。需要先离场再召唤的效果必须显式使用 Sequence。

有效召唤优于移动。多个召唤优先选择槽位控制方提供的请求，同优先级多候选使用全局 RNG。无效召唤不妨碍剩余合法移动；成功召唤才分配卡牌与实体身份，并产生后续入场触发。

移动方向沿用 ADR-011 的协议设置。奇数路中心的两侧都可移动时使用 RNG；如果有效召唤将同时击败两个方向，方向选择不会影响结果，不消费该次 RNG。每次实际随机决策及候选集合进入可复核的 CommitPlan。
