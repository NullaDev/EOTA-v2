# ADR-025：附加效果及玩家观察者

- 状态：Proposed
- 日期：2026-09-09

## 决定

grantEffect 将编译后的效果定义附加到随从、场地或玩家；可永久存在，也可具有通用回合期限。随从/场地附加效果以承载者为来源，来源离场时冻结；玩家观察者不依赖最初施法实体继续存活。

附加效果与印刷效果使用同一触发和续执行管线。死亡/离场观察者从帧开始集合冻结，本帧新获得的观察者不追溯观察本帧已经产生的死亡。回合结束触发先完成，再清理到期期限。

玩家只支持有意义的友敌入场、死亡、离场、战斗、敌方攻击和友方法术观察；实体支持自身及友敌战场触发。附加充能根、施法根和战斗伤害贡献根暂不开放。编译器拒绝没有实现的承载者/触发器组合，避免内容编译成功却永不触发。

公开视图只提供效果定义标识、触发种类与剩余期限；持久化另保存完整 IR、来源和稳定身份，不能把私有保存对象直接作为传输 DTO。
