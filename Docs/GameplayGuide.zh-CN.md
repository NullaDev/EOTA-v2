# 当前客户端玩法与房间规则

更新于 2026-09-15。本文说明当前客户端的玩法。详细规则以当前对战协议、卡牌定义和 [ADR](ADR/README.md) 为准。

第一次游玩请先阅读 [新手教程](BeginnerGuide.zh-CN.md)，从开局操作、九阶段回合到战斗、以太和充能逐步了解；本页侧重卡组管理、协议设置与房间规则。

制作自定义卡牌请阅读 [Mod 开发者 JSON 编写指南](CardJsonDesignGuide.zh-CN.md)，可复制的源文件见 [教学示例](Content/Examples/README.zh-CN.md)。

## 选择模式与管理卡组

- **人机对战**：选择双方牌组和简单／普通／困难难度。
- **本机双人**：两人轮流操作；切换席位先进入交接界面，由下一位玩家确认后展示其手牌。
- **本机开服**：只需选择自己的参考牌组、房间名、端口和协议，无需知道对手的牌组。启动后点击“自己加入”，将“玩家二邀请”交给对手；另一位玩家在“加入服务器”中选择自己的牌组。
- **牌组工坊**：先选已有卡组，或点击“新建卡组”选择职业，再编辑卡牌。返回列表保留本次运行的草稿，点击保存才写入文件。自建卡组和未保存的新草稿右上角有“删除”，确认后删除；取消则保留。四个默认牌组作为构筑模板保留。

当前每个职业有 50 张可构筑卡与 2 张衍生卡，另有 22 张共享中立卡。新建时可在“起始牌组”中选空白牌组或本职业的三个体系模板之一；选中模板后可以继续改牌，保存后用于各对战模式。模板按 40 张默认构筑规则设计，不符合当前协议或启用卡池的模板会自动隐藏。各体系思路与完整牌表见 [十五套体系牌组](Content/ArchetypeDecks.zh-CN.md)。

牌组重命名更新同一个保存文件，删除会移除对应文件及该牌组草稿。卡牌图鉴独立于构筑界面；构筑卡池按当前协议和所选职业自动筛选。

## 对战协议

进入“对战协议 → 构筑与疲劳”可以修改以下设置，保存后用于构筑、人机、本机双人和新建房间。已开始的房间继续使用开服时确定的协议。

| 项目               | 含义                                                         | 默认值 |
|--------------------|--------------------------------------------------------------|--------|
| 牌组张数           | 每位玩家牌组必须恰好达到的总张数，范围 1–256                 | 40     |
| 每种已选卡最少张数 | 某个卡牌 ID 加入牌组后，至少需要的副本数；不要求所有卡都入组 | 1      |
| 每种卡最多张数     | 每个卡牌 ID 的副本上限，最多可设 256                         | 3      |
| 构筑规则           | 正常、仅本职业、无限制                                       | 正常   |
| 疲劳规则           | 不疲劳、递增伤害、疲劳即死                                   | 不疲劳 |

“正常”允许本职业与中立卡；“仅本职业”排除中立及其他职业；“无限制”允许任何职业的基础卡。三者均不直接开放衍生卡或测试卡。卡牌 ID 必须存在，重复副本以数量记录。

例如总张数 24、最少 2、最多 4，可以放入 12 种卡各 2 张，也可以选择其他满足总数和副本限制的组合。最低数量必须为正且不高于总张数，最高数量不得低于最低数量。起手张数不能超过牌组张数或手牌上限。不合法的设置不会保存。

修改协议不会擅自删除已保存牌组中的卡。打开旧牌组时，不符合职业或数量要求的条目会标红，玩家可自行修正；保存和开始对局时再次校验。“填入默认牌组”按当前协议生成；若当前卡池无法满足所设总张数和副本数，应先调整协议或补充基础卡。

## 抽牌与疲劳

疲劳以**每位玩家自己的空牌库抽牌次数**累计，不在回合切换或重新连线时重置。牌库刚好被抽空并不会立刻疲劳，下一次尝试抽牌才触发。

| 规则              | 空牌库抽牌的结果                                                         |
|-------------------|--------------------------------------------------------------------------|
| 不疲劳            | 抽不到牌，不扣生命                                                       |
| 疲劳伤害 1、2、3… | 第一次失去 1 点生命，第二次 2 点，第三次 3 点，依次递增                  |
| 疲劳即死          | 抽空牌库后，下一次尝试抽牌时直接斩杀该玩家英雄；当前帧结束后统一判定胜负 |

抽走最后一张牌本身不会触发斩杀；如果同一帧还要求继续抽牌，紧接着的空抽就会触发。斩杀不会被同帧治疗抵消，也不会提前中断该帧其他结算；双方在帧结束时均死亡则判平局。

每回合抽牌和卡牌效果抽牌遵守相同规则。一次效果要求抽 3 张、牌库只剩 1 张时，先抽走该牌，再产生两次空抽；首次疲劳使用递增规则时总共失去 3 点生命。

手牌满时，有牌可抽仍按烧牌处理；牌库已空则照常触发疲劳。牌库尚有牌但没有符合指定筛选条件的牌时，不视为空牌库疲劳；生成卡牌也不计作抽牌。双方在同一结算帧中同时死亡则为平局。疲劳次数保存在对局状态、断点和回放中，可在英雄信息的提示中查看。

## 联机确认

加入者先“核对房间”，可打开完整协议明细，然后确认自己的牌组。服务器按房间协议检查张数、副本、职业、来源和卡牌定义；两位玩家均通过才开始。参考牌组只是建议，确认之后该席位本局的牌组才锁定。

双方可以使用不同牌组；仅要求两个牌组用到的全部卡牌及递归关联卡牌定义一致，未用到的卡可以不同。界面不会向房主泄露对手完整牌组。卡牌编辑器支持单卡及整个内容包导出，需同步相关定义时可使用 [内容包导入导出](../tools/README.zh-CN.md#游戏内卡牌编辑器p10)。
